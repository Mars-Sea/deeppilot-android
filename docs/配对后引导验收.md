# 配对后引导验收

## 一、实现

1. 配对成功后一次性展示 4 页全屏横向分页：已连接电脑、实时会话与流式输出、审批与提问、通知。可跳过、可返回，页码点可点；走完或跳过后先写入完成状态，显示约 1.2 秒「一切就绪」再淡出。决策见《决策记录》第四章。
2. 完成状态按设备记录（`onboarding.completedVersion`、`onboarding.armedVersion`）：升级前已配对的用户不展示；新用户在未配对时被标记，配对后展示一次；完成后解除配对再重配也不再展示；中途退出则下次冷启动再次展示。
3. 通知授权的申请时机改变：原先 `MainActivity.onPaired()` 在配对完成后立即申请，并且每次冷启动都会再申请；现在待引导的用户由末页触发，前台服务照常启动。末页按通知状态分支：未决定为「开启通知」加「稍后再说」，已授权为「完成」，已拒绝为「前往系统通知设置」加「稍后再说」。
4. 入场动效按时间轴驱动，静止态即终态；系统动画缩放为 0 时直接取终态、按钮翻页直接切换，第 3 页改为静止展示待审批半屏；字体放大到 1.5 倍及以上隐藏舞台。设置页「关于」末行「重看引导」以重看模式打开，不记录状态、不申请权限，末页按钮为「完成」。
5. 纯逻辑（状态判定、翻页与按钮分支、通知三态、时间轴）在 `core`，界面在 `app`；调试构建附带离线预览入口 `OnboardingPreviewActivity`，不需要配对主机。

## 二、本地证据

1. 2026-10-17：`core` 共 106 项测试通过（含新增 36 项：状态 8、翻页与通知三态 10、时间轴 18），`:app:assembleDebug` 通过。构建需要 JDK 21（见《决策记录》四-12）。
2. API 37 模拟器上用调试预览入口逐页截图核对：4 页的版式、浅色与深色、已授权 / 已拒绝 / 未决定三种末页、真实的系统通知授权框（点「开启通知」弹出，拒绝后写入 `onboarding.notificationAsked`，随后末页变为「前往系统通知设置」）、完成态。
3. 入场过程用连续截图核对了中间帧：第 1 页线稿描边、扫码框一闪与虚线；第 2 页气泡上浮、转圈与逐字输出的光标；第 3 页半屏滑入与状态点脉冲，之后「已允许」；第 4 页通知逐条落下。系统动画缩放设为 0 后，各页直接显示终态，第 3 页为待审批半屏。
4. 无障碍树（uiautomator 导出）只含当前页的元素：上一页、顶栏按钮、舞台说明、标题、正文、「第 n 页，共 4 页」与主按钮；离开的页面不残留。返回键：第 3 页返回到第 2 页，再回到第 1 页，第 1 页按系统默认退出。
5. 字体 2.0 倍：舞台隐藏、整页可读；主按钮「前往系统通知设置」折成两行并完整显示，「稍后再说」不被裁切。模拟 1600×2560 的宽屏：内容列限宽 480dp 并居中。重看模式加深色：末页为「完成」，没有「稍后再说」。

## 三、需抽查的改动

共用的 `ProminentButton` 把固定高度改成最小高度，加了上下 8dp 内边距并让文字居中，目的是大字号下主操作不被裁切。正常字号下按钮高度与改动前一致（已在引导末页核对），但没有逐页回归，请抽查所有用到它的位置：模型选择（`ModelPicker`）、新建会话（`NewSessionPicker` 两处）、审批与提问面板（`PendingSheets` 四处）、配对页（`PairScreen` 两处），重点看正常字号下高度不变、大字号下标签折行时不被裁切。

## 四、待验收

1. 真实首次配对触发叠加层：模拟器上没有已配对主机，叠加层与 `MainActivity` 门禁只做了编译与逻辑审阅，未实际走通。需要一台全新安装并扫码配对的真机验证：配对完成瞬间不弹系统通知授权框，只在末页点「开启通知」时弹出；选「稍后再说」后之后冷启动不再弹框也不再出现引导；中途杀掉应用下次冷启动再次出现。
2. 从旧版升级且已配对：不出现引导，通知申请行为与旧版一致。
3. 设置页「关于」末行「重看引导」的实际点击流程（重看路由走的是同一个 `OnboardingScreen` 的重看模式，已在预览里验证）。
4. Android 12 及以下的通知分支（模拟器是 API 37，只覆盖 13 及以上）：用户在系统里关闭通知时末页应为「前往系统通知设置」；该规则只有 `NotifyState` 的单元测试覆盖。
5. 前台服务「保持连接」保活、国行机电池白名单，对应末页文案「保持连接开启时才有通知」的实际效果。
6. TalkBack 实际朗读：页码的「下一页 / 上一页」自定义动作、翻页后标题的播报（标题是实时区域）、舞台说明的朗读顺序。
7. 动效流畅度与功耗（模拟器只能看到过程）；折叠屏展开态与真实平板；预测性返回手势。未发布。
