# 目录缓存验收

## 一、实现与更新

1. 使用核心层 `CatalogCache`，应用层仅注入私有缓存目录。技能和指令并行读取，模型目录在进入会话/打开选择器时按需检查；内存五分钟直接复用，过期与磁盘恢复先显示旧列表并后台更新。
2. 缓存文件格式版本 1，不兼容格式、损坏、异常时间或超过七天自动重建；相同键请求合并，失效代次阻止旧结果回填，解除配对清理对应目录。当前选择及权限不落盘。
3. `s2c.models.changed` 接收模型实时选择并使对应会话模型目录失效。旧桥接仍以有效期与手动刷新兜底；供应商账号/凭据不保存在缓存中。

## 二、本地证据

1. 2026-10-16：70 项核心测试、调试包构建通过，新增七项缓存回归与命令/分块回归；覆盖重启、过期、并发合并、空目录、错误保留、身份/主机/会话隔离、连接变化、取消与坏格式重建。
2. 调试专用 `SkillCompletionActivity` 使用真实产品输入器与真实目录缓存，合成目录替代主机。模拟器验证再次打开读取计数仍为 1，手动刷新后为 2；终止重启后读取计数重置为 1，在合成主机仍等待响应时已显示旧 `/review` 与后台更新提示；延迟只在调试验收入口注入。
3. 截图已核对紧凑行、缓存/后台更新提示与键盘避让；模拟器合成延迟不作为真实网络速度测量。

## 三、待验收

1. 当前支持主机的实际目录更新、真实模型选择推送、冷启动与弱网耗时；供应商账户/凭据变更后刷新正确。
2. 真机解除配对、重新配对、同会话编号跨主机隔离、低磁盘与系统回收缓存，以及不同输入法和无障碍。未发布。
