# 系统指令验收

## 一、实现

1. 可选 v2 `commands` 能力启用目录、执行、权限、反馈和日志分块；旧桥接继续原有输入。支持主机提供的 `/compact`、`/goal`、`/plan`、`/permission`、`/feedback`、`/export`，目录依主机组合而定。
2. `/model`、`/file` 复用既有原生选择器，裸权限和反馈命令打开专用界面；完全访问与自动审查先确认。源定义变化时拒绝旧权限操作。
3. 命令分流不创建普通用户消息；图片与文档正文按目录附件声明提交，ZIP 使用连续分块并校验最终字节。失败保留草稿，不自动重试。

## 二、证据与待验收

1. 核心命令解析、旧能力缺省、定义身份、参数/附件序列化、分块请求相关与坏块异常隔离通过；70 项总核心测试及调试包构建通过。
2. 2026-10-16 实际应用模拟器通过正常单次配对连接独立官方 `0.2.1-alpha.4` 主机：真实技能/命令目录可见，点选 `/compact` 只补全，发送后收到压缩 6 条历史的结果；`/model` 打开原生列表并切换为测试模型甲。权限显示只读当前值，完全访问先确认且取消未切换，工作区写入可正常选择。
3. 原生反馈表单保存 `android-live-feedback-proof`，`/export` 发送后打开系统分享。取回实际 `cache/command-exports` 下的 ZIP 完整解包，核对了子会话、文档附件及对应 `feedback/record` 事件。未向其他分享应用发送文件。
4. 官方主机另有 25 项桥接集成通过，覆盖压缩摘要、目标/计划参数、附件准入、模型推送、七类反馈与完整归档；模型仅返回本机合成文本，不代表实际模型质量。
5. 真机输入法、大字体/朗读、图片附件、弱网断线、大归档资源占用，以及另两版主机同等业务集成仍待验收。离线入口只证明组件交互；未发布。
